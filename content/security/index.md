# Security

MissionsReady approaches security as an ongoing practice that protects ministry continuity, privacy, and trust.

## Reproducible Builds

A reproducible build records the source, dependencies, configuration, and process used to create an application or image. This makes it possible to review and recreate a known-good result.

## Wolfi Rebuilds

Wolfi is a lightweight Linux distribution designed for secure, minimal, container-focused workloads. Wolfi rebuilds help keep container images current while maintaining a clear record of their software components.

## SBOMs

A software bill of materials (SBOM) is an inventory of the software components and versions included in an application or image. SBOMs help operators understand what is deployed and whether a security advisory applies to it.

## CVE Differentials

A CVE differential compares vulnerabilities between two builds or releases. It shows which findings were introduced, resolved, or retained, helping teams focus on meaningful changes.

## Why Security Matters

Ministries rely on technology to serve people, coordinate volunteers, communicate, and preserve important records. Practical security reduces disruption, protects sensitive information, and gives ministry teams a clear path to update and recover their services.
