# MissionsReady.org

MissionsReady.org is the public website for MissionsReady, a platform that helps ministries adopt secure, reproducible, and ministry-friendly technology.

## Ecosystem

The website introduces MissionsReady capabilities, ministry-ready applications, security practices, and adoption guidance.

- [MissionsReady Documentation](https://github.com/MissionsReady/docs-main)

- [FreeShow Application](https://github.com/MissionsReady/applications-freeshow)
- [OpenLP Application](https://github.com/MissionsReady/applications-openlp)

## Ministry-Friendly Goals

MissionsReady is designed for ministries with limited time, staff, and technical resources. The website explains technology in clear language, provides practical deployment guidance, and connects ministry needs with secure defaults and repeatable tools.

## Reproducible Infrastructure

MissionsReady promotes infrastructure that can be inspected, rebuilt, updated, and recovered from documented inputs. Reproducible builds, Wolfi rebuilds, SBOMs, and CVE differentials help ministries operate technology with greater confidence and continuity.
